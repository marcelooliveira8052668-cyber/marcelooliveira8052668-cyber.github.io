# Portfólio — Prof. Marcelo Oliveira

Portfólio profissional com **32 projetos front-end**, cada um em um card com foto real do site e um visualizador de código integrado.

## 🚀 Publicação (GitHub Pages)

```bash
gh repo create marcelooliveira8052668-cyber.github.io --public --source=. --push
```

Depois ative o Pages no repositório (Settings → Pages → branch `main`, pasta `/root`).

## 📁 Estrutura

| Caminho | Descrição |
|---|---|
| `index.html` | Página principal do portfólio |
| `style.css` | Estilos (moderno/clean, responsivo) |
| `app.js` | Cards, filtros e visualizador de código |
| `screenshots/` | Fotos reais de cada projeto (32) |
| `<NomeDoProjeto>/` | Código-fonte completo de cada projeto |

## ✨ Funcionalidades

- Cards com **foto real** do projeto
- Clique em **"Ver Código"** abre o visualizador com destaque de sintaxe
- Commentário de autoria (`Desenvolvido por Prof. Marcelo Oliveira`) no topo de cada arquivo
- Filtros por categoria (E-commerce, Sistema, Educação, Site, Jogo, Ferramenta, SENAI, App Web, Social)
- Layout responsivo (celular, tablet e desktop)

## 🛠️ Tecnologias

HTML5 · CSS3 · JavaScript (ES6+) · React · Vite · Bootstrap · Leaflet · OpenStreetMap
