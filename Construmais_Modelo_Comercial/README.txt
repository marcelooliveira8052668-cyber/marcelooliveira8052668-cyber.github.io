CONSTRUMAIS — MODELO COMERCIAL

Este projeto é um template de loja de materiais de construção.

ARQUIVOS
- index.html: estrutura do site.
- style.css: visual responsivo.
- script.js: produtos, carrinho, checkout, estoque e fluxo de pedido.

ANTES DE ENTREGAR AO CLIENTE
1. Troque nome, telefone, endereço e horários.
2. Troque as imagens por fotos reais do cliente.
3. Cadastre produtos, preços e estoque reais.
4. Configure WhatsApp e links sociais.
5. Configure o domínio/hospedagem.
6. Teste carrinho, checkout e versão mobile.

IMPORTANTE
O checkout, estoque e pedidos desta versão são uma demonstração local usando localStorage.
Para uma operação real com cliente, loja, estoque e entrega sincronizados em aparelhos diferentes,
conecte o projeto ao Firebase/Firestore ou outro backend e integre um gateway de pagamento.

PRÓXIMA EVOLUÇÃO COMERCIAL
- Login de administrador
- Firebase Authentication
- Firestore em tempo real
- Painel de estoque
- Painel de pedidos para loja
- Status: recebido, separando, pronto, saiu para entrega, entregue
- Notificação/WhatsApp ao cliente
- Integração real de PIX/cartão
- cálculo de frete por CEP
- emissão/integração fiscal conforme necessidade do cliente
