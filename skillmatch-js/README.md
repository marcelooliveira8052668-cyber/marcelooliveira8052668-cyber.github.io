# SkillMatch JS

## Sobre
Sistema que compara candidato com vagas de Front-End.

## Funcionalidades
- Compatibilidade %
- Habilidades faltantes
- Melhor vaga
- Recomendação de estudo

## Tecnologias
- JavaScript
- HTML
- CSS

## Conceitos usados
- Arrays (map, filter, reduce)
- Objetos
- Classes e herança
- this
- Callback
- Closure
- Promise
- async/await

## Como executar
Abrir index.html no navegador.

## Internet e Cliente-Servidor
O navegador (cliente) solicita dados a um servidor. Neste projeto, simulamos isso com Promise.

## Extensões VS Code
- Live Server
- JavaScript ES6 Snippets
